# S03｜What is SAP ERP?

- 網址：https://www.techtarget.com/enterprise-software/definition/What-is-SAP-ERP
- 取得日期：2026-11-11
- 來源類型：科技媒體

## 原文重點

- SAP ERP 是 SAP 公司開發的企業資源規劃軟體，目前被視為舊版（legacy），由 S/4HANA 取代。
- 文章寫 SAP 會支援既有 ERP 客戶到 2027 年 12 月。
- 主要模組：FI/CO（財務會計與管理會計）、SD（銷售與配送）、MM（物料管理）、PP（生產規劃）、QM（品質管理）、PM（工廠維護）、PS（專案系統）、CS（客戶服務）、HCM（人力資本管理）。
- 原文：各模組在「an integrated environment with data from each module stored in a central database」中運作，資料在模組之間流動「without redundant data entry」。
- ECC（ERP Central Component）是安裝最多的 SAP 系統，2004 年推出，接替 R/3，通常是地端、三層式架構（展示層、應用層、資料庫層）。
- S/4HANA 於 2015 年推出，完全建立在 SAP HANA 記憶體內資料庫上，SAP 的說法是要「reduce complexity and replace SAP ECC」。
- S/4HANA 可以地端、雲端或混合部署；S/4HANA Cloud 是 SaaS 版本。
