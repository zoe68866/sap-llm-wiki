# S05｜ABAP Overview（ABAP 官方說明）

- 網址：https://help.sap.com/doc/abapdocu_752_index_htm/7.52/en-us/abenabap_overview.htm
- 取得日期：2026-11-11
- 來源類型：官方

## 原文重點

- 原文：「ABAP is a programming language developed by SAP for the development of business applications in the SAP environment.」
- ABAP Objects 讓 ABAP 支援物件導向。
- 存取資料庫表格直接整合在語言中：「Access to database tables is fully integrated into the language.」
- ABAP Dictionary 是儲存資料型態與相依關係的資料庫，定義可以被其他所有開發物件使用，也管理資料庫表格、檢視、鎖定物件。
- ABAP 是 Application Server ABAP（AS ABAP）的程式介面，使用 ABAP 需要安裝 AS ABAP。
- 本頁沒有說明 ABAP 這個縮寫的全名。
