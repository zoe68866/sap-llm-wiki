# S02｜What is SAP?（SAP 是什麼）

- 網址：https://sap.com/ukraine/about/what-is-sap.html
- 取得日期：2026-11-11
- 來源類型：官方

## 原文重點

- SAP 來自德文原名 Systemanalyse Programmentwicklung，頁面英譯為 System Analysis Program Development，後來縮寫為 SAP。
- 1972 年創立，1973 年推出第一個商業產品。
- 總部在德國瓦爾多夫（Walldorf）。
- 軟體涵蓋從採購原料、生產到客戶服務的商業流程，可以裝在公司自己的機房（on-premises）或使用雲端。
- ERP 是 enterprise resource planning，原文：「ERP software includes programs for all core business areas」，例如採購、生產、銷售、財務、人資。
- 傳統做法是各部門資料存在不同資料庫，難以分享、容易出錯；SAP 把資料集中管理。原文：「By centralising data management, SAP software provides multiple business functions with a single view of the truth.」
- 頁面寫有超過 105,000 名員工、超過 2.3 億雲端使用者、超過 100 種解決方案。
