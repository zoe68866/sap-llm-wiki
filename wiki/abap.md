# ABAP 與 ABAP Dictionary
> ABAP 是 SAP 自己的程式語言；ABAP Dictionary 定義資料型態和資料表。

## 重點
- ABAP 是 SAP 為了在 SAP 環境中開發商業應用而發展的程式語言 [S05]
- ABAP Objects 讓 ABAP 支援物件導向 [S05]
- 存取資料庫直接整合在語言中 [S05]
- ABAP Dictionary 儲存資料型態，定義可以被其他所有開發物件使用，也管理資料庫表格 [S05]
- 用 SE11 進入 ABAP Dictionary [S07]
- 建資料表的順序：網域 → 資料元素 → 資料表，每一步都要啟用 [S07]
- 自建物件用 Z 或 Y 開頭 [S07]
