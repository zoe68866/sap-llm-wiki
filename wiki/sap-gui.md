# SAP GUI 與交易碼
> SAP GUI 是操作 SAP 系統的畫面，用交易碼（T-code）進入各個功能。

## 重點
- SAP GUI（SAP Graphical User Interface）是和 SAP 系統互動的軟體，可以是桌面程式或在瀏覽器執行 [S06]
- 登入需要用戶端、帳號、密碼、登入語言 [S06]
- 介面依登入語言顯示中文、英文或德文，同一個按鈕有三種名稱，例如啟用（Activate / Aktivieren） [S07]
- 交易碼是每個交易的唯一代碼，原本 4 個字元，現在最長 20 個字元 [S06]
- 在命令欄輸入交易碼後按 Enter 進入功能 [S06]
- /n 取消目前交易，/nxxxx 取消後開啟 xxxx，/oxxxx 開新工作階段 [S06]
- 用 /n 或登出時沒有存檔，修改會被取消 [S06]
- 狀態列綠色是成功、黃色是警告、紅色是錯誤 [S07]
